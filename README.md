## 📝 필사 용지 메이커

사용자가 입력한 텍스트를 A4 규격에 맞춘 **원고지 및 줄노트**로 조판해 주는 웹 애플리케이션입니다.

## 🚀 핵심 기능

1. **필사 용지 및 원고지 모드 생성:**
   - **따라 쓰기 지면 제공:** 연한 명조체 텍스트 가이드라인이 비쳐 보여 바른 글씨 연습을 도와줍니다.
   - **빈 원고지 지면 제공:** 가이드 없이 실제 출력하여 본인이 직접 글씨를 쓸 수 있는 빈 격자를 출력합니다. 표준 20칸(가로 200자 원고지/ 세로 500자 표준형)을 비롯하여 10칸, 12칸, 14칸, 16칸, 18칸, 22칸, 24칸까지 용지 크기에 맞게 자동으로 행과 열의 격자를 연산하여 생성합니다.
   - **줄 노트 모드:** 원고지 격자 없이 가로줄만 표시하여 보다 자유롭고 긴 호흡의 필사를 지원합니다.
   - **줄 사이 간격 추가 모드:** 전통 원고지와 같은 줄 사이 간격을 추가 합니다.
   - **가로 모드 / 세로 모드 선택 가능:** A4 기준 세로 모드와 가로 모드를 선택할 수 있습니다. 가로 모드를 선택할 경우 원문 보기는 2단으로 구성됩니다.
2. **원고지 가이드 표시**
   - 십자, 왼쪽 세모, 위쪽 세모, 네모 가이드를 표시하거나 끌 수 있습니다.
   - 각 가이드 별로 색깔과 투명도를 지정할 수 있습니다.
3. **원고지 규칙 적용**
   - 행 끝에 도달했을 때 온점(.), 반점(,), 큰따옴표(”), 물음표(?), 느낌표(\!) 등의 문장부호가 위치할 경우, 다음 행 첫 칸으로 넘어가지 않고 현재 행 마지막 칸에 물리적으로 압축 합산(isSqueezed, squeezedPunct)하여 가독성을 높입니다.
   - 연속 문장부호 쌍(.”, ?” 등)을 한 칸에 병합합니다.
4. **사용자 맞춤형 옵션**
   - **학교 이름, 꼬리말 등 삭제 기능:** 머리말의 학교 이름과 학년 반, 꼬리말의 내용을 삭제함으로써 원고지만 남겨 프린트할 수 있는 기능을 제공합니다.
   - **정밀 조정:** 따라 쓰기 용지의 글씨 출력 위치를 슬라이더로 조절할 수 있는 기능을 지원합니다.
   - **원고지 선 색 및 불투명도 조정:** 원고지의 선과 가이드 점선의 색과 불투명도 조절 기능을 지원합니다.
   - **메타데이터 자동 보존:** 사용자가 입력한 제목, 원문 및 원고지색 등의 설정 값 그리고 마우스로 용지 위의 학교명, 학년/반, 이름, 꼬리말 영역을 클릭해 직접 수정한 정보는 localStorage에 백업됩니다.
   - **저장 및 불러오기:** 입력한 내용과 설정을 json 형태의 파일로 저장하고 불러올 수 있는 기능을 제공합니다.

## 🖨️ 인쇄 설정 필수 체크 리스트

1. **배경 그래픽 인쇄**: 반드시 '켬' 또는 '체크 활성화'해야 원고지의 색상 테두리와 가운데 가이드 점선이 또렷하게 출력됩니다.
2. **여백**: 기본 여백이 넓어 짤릴 경우 **'없음'** 또는 '최소 여백'으로 설정해 주세요.
3. **머리글과 바닥글**: 브라우저 인쇄 창에서 이 옵션을 '해제(체크 해제)'해 주셔야 인쇄 일시, 웹 주소 같은 불필요한 정보가 출력물 상하단에 묻지 않습니다.
